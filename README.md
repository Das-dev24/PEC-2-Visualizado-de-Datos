# PAC2 - Exploración y Aplicación de Técnicas de Visualización de Datos

Presentación web interactiva para la defensa de la PAC2 de la asignatura **Visualización de Datos** de la Universitat Oberta de Catalunya (UOC).

- **Autor/a:** Diego Alonso Soria
- **Semestre:** 1er Semestre 2026-2027

## Contenido y Fuentes de Datos

1. **Grupo I — Bar Chart:** Inversión en I+D (% del PIB) en Europa.  
   *Fuente:* [Eurostat Data Browser (`rd_e_gerdtot`)](https://ec.europa.eu/eurostat/databrowser/view/rd_e_gerdtot/default/table?lang=en)
2. **Grupo II — Waffle Chart:** Mix de generación de energía renovable.  
   *Fuente:* [Red Eléctrica (REData)](https://www.ree.es/es/datos/generacion/estructura-renovables) y [Eurostat](https://ec.europa.eu/eurostat/statistics-explained/index.php?title=Renewable_energy_statistics)
3. **Grupo III — Ridgeline Chart:** Distribución estacional de temperaturas.  
   *Fuente:* [AEMET OpenData](https://www.aemet.es/es/serviciosclimaticos/datosclimatologicos) y [Copernicus ERA5](https://cds.climate.copernicus.eu/)
